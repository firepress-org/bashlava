# Abstract

This repo is a Bash-based workflow helper centered on `bashlava.sh`, mainly for Git/GitHub release-flow shortcuts such as branch creation, commit, PR, merge, version, tag, and release. Use it to route quickly to the executable command logic, the helper/component scripts it depends on, and the small doc set that explains command prompts, next moves, and a few troubleshooting cases.

## Use this when
- You need the source of truth for BashLava command behavior.
- You are tracing a user-facing command such as `e`, `c`, `pr`, `mrg`, `v`, `t`, or `r`.
- You need the helper/docs path for command help, next-step prompts, or GitHub CLI issues.
- You want to distinguish shipped command logic from examples, drafts, or backlog notes.

## Main areas
- `bashlava.sh` — Main executable and primary command logic.
- `components/` — Helper namespaces, aliases, examples, and utility experiments.
- `docs/` — Help text, command follow-up notes, and troubleshooting docs.
- `./.overview.md#reference-map` — Detailed map

## Out of scope
- Stable project requirements; `REQUIREMENTS.md` is mostly backlog notes.
- A polished installation or architecture guide; the README says it is outdated.
- Secrets or local user config under ignored paths such as `private` or `.env`.
